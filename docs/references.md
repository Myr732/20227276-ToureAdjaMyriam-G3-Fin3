# Références — Projet F3 : Prévision de l'inflation

## Source des données
- Organisme producteur : U.S. Bureau of Labor Statistics (BLS)
- Plateforme : Federal Reserve Economic Data (FRED)
- Série : CPIAUCSL
- Description : Indice des prix à la consommation américain, corrigé des variations saisonnières
- Fréquence : mensuelle
- URL : https://fred.stlouisfed.org/series/CPIAUCSL
- Date d'extraction : 25/11/26
- Fichier : data/raw/CPIAUCSL.csv

## Utilisation
L'indice des prix servira à calculer un taux d'inflation sur douze mois. Les transformations et l'analyse seront réalisées pendant l'épreuve.

## Limites
Les données consultées aujourd'hui peuvent avoir été révisées par rapport aux versions disponibles historiquement. Ce point sera discuté dans le rapport.
